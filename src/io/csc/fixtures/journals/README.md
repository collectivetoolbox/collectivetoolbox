# CSC State Journal Multi-Revision Test Fixtures

This directory maintains authentic, reproducible test fixtures for every historical and current revision of the `csc` state journal format. All fixtures are generated by compiling genuine `ctoolbox` releases at the latest buildable commit before each successive format migration.

## Format Revisions and Provenance Commits

### 1. Revision 1: `v1_ctbmeta1`
- **Files**: `v1_ctbmeta1.cscjournal`, `v1_ctbmeta1.cscdesc`
- **Magic**: `CTBCSCJ\x01`
- **Preservation Record**: `CTBMETA1` (unstructured JSON preserving POSIX mode, uid, gid, mtime, atime, streams, and extents, prior to semantic identity encapsulation).
- **Source Commit**: `d90071e257ebc4883e6027a4d55734fa0a484392` (*fix: Slightly less dubious edits. Still kind of dubious.*) — the last buildable commit before `CTBMETA2` was introduced in `8a1f3786d`.

- **Source Commit**: `HEAD` / `main` branch.

## Regenerating Fixtures

The complete set of fixtures can be regenerated automatically from scratch by running:

```bash
# Clone from GitHub and generate all revisions:
./scripts/generate-journal-fixtures

# Or clone from local repository:
./scripts/generate-journal-fixtures --local
```

The script clones the repository, checks out the verified commits above, compiles `ctoolbox`, executes `csc` to produce the state journal, validates magic and preservation record headers, and installs the resulting fixtures into this directory.
