Note that some entities (e.g. in HTML5 and MathML) have multiple characters represented by a single entity, like `0226B 00338,NotGreaterGreater;`.

- `entities-html32.csv`: Data from https://www.w3.org/TR/2018/SPSD-html32-20180315/#latin1
- `entities-netscape-1999.csv`: Data from https://www.rssboard.org/html-entities
- `entities-xml.csv`: Data from https://www.w3.org/TR/REC-html40/sgml/entities.html and https://en.wikipedia.org/wiki/List_of_XML_and_HTML_character_entity_references#Character_entity_references_in_HTML
- `entities-html4.0.csv`: Data from https://www.w3.org/TR/REC-html40/sgml/entities.html
- `entities-html5.csv`: Data from https://dev.w3.org/html5/spec-LC/named-character-references.html
- `entities-mathml.csv`: Data from https://www.w3.org/2003/entities/2007/htmlmathml-f.ent
