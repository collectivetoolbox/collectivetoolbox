Welcome to the first ever edition of the $SiteName newsletter! At the moment, it's just going out to me, myself, and I, but it'll be up on the web too for the morbidly curious.

Anyway, here's what's substantially new since I first published $DomainName in mid-December:

- Broke the project up into multiple smaller packages that can be independently compiled. My hope was that this will allow for faster iteration (quicker linter results, quicker rebuilds, etc.) by caching more steps of the build. While some compile-time code generation seems to be preventing caching, I think it does at least allow those steps to be parallelized.
- Finished replacing the inter-process communication (IPC) with a new implementation. It no longer steadily uses a trickle of CPU when idle, and should unblock the "user list" feature that was blocked on a bug in the old version.
- Added a new installer.
